Sheet 05 — Case study

Hotel operations: room-service delays

LuxurStay Hotels is getting complaints about slow room service, and satisfaction has fallen below its 4.5 target. Working to the Head of Operations’ brief, I cleaned the branch data, measured response times by service and branch, pulled Meal and Laundry requests in EMEA and LATAM, and found where ratings fall short.

ToolsSQL, PostgreSQL
Databranch, service and request tables
SourceDataCamp practical exam
SkillsData cleaning, aggregation, CTEs, joins, HAVING

What I found

100

branches cleaned to the data description: valid regions, 1 to 400 rooms, opening years from 2000 to 2023.

385

service-and-branch combinations measured for average and maximum response time.

5,047

Meal and Laundry requests across EMEA and LATAM branches identified for management.

215

service-and-branch combinations average below the 4.5 rating target.

How I approached it

  • Cleaned the branch table with CASE, TRIM, UPPER and NULLIF, replacing invalid or missing values with the defaults in the brief.
  • Used GROUP BY for average and maximum response times by service and branch.
  • Joined the request table to two filtered CTEs (locations and services) for the Meal and Laundry list, and used HAVING to flag averages under 4.5.

The code and output

Taken from my DataCamp Workspace notebook for this project.

Task 1: clean the branch table
SELECT 
	id,
	CASE
		WHEN UPPER(TRIM(location)) IN ('EMEA', 'NA', 'LATAM', 'APAC') THEN UPPER(TRIM(location))
		ELSE 'Unknown'
	END AS location,
	CASE
		WHEN total_rooms BETWEEN 1 AND 400 THEN total_rooms::INTEGER
		ELSE 100
	END AS total_rooms,
	ROUND(COALESCE(staff_count, total_rooms::INTEGER * 1.5))  AS staff_count,
	CASE
		WHEN NULLIF(opening_date, '-')::INTEGER BETWEEN 2000 AND 2023 
		THEN NULLIF(opening_date, '-')::INTEGER 
		ELSE 2023
	END AS opening_date,
	CASE
		WHEN INITCAP(TRIM(target_guests)) IN ('Leisure', 'L.') THEN 'Leisure'
		WHEN INITCAP(TRIM(target_guests)) IN ('Business', 'B.') THEN 'Business'
		ELSE 'Leisure'
	END AS target_guests
FROM branch;

Task 3: Meal and Laundry requests in EMEA and LATAM
WITH location_query AS (
	SELECT id, location
	FROM branch
	WHERE location IN ('EMEA', 'LATAM')
),
service_query AS (
	SELECT id, description
	FROM service
	WHERE description IN ('Meal', 'Laundry')
)
SELECT
	sq.description,
	lq.id,
	lq.location,
	r.id AS request_id,
	r.rating
FROM request AS r
JOIN location_query AS lq
ON r.branch_id = lq.id
JOIN service_query AS sq
ON r.service_id = sq.id;

Task 4: service and branch pairs below the 4.5 target
SELECT
	service_id,
	branch_id,
	ROUND(AVG(rating), 2) AS avg_rating
FROM request
GROUP BY service_id, branch_id
HAVING AVG(rating) < 4.5
