Sheet 05 — Case study

Customer support ticket analysis

Tech Solutions Inc. has seen customer satisfaction slide. Working with its support team, I cleaned the ticket table to a data description, compared response times across ticket categories, and joined survey ratings to Bug and Installation Problem tickets.

ToolsSQL, PostgreSQL
Datasupport and survey tables, 1,987 tickets
SourceDataCamp sample practical exam
SkillsData cleaning, aggregation, joins

What I found

1,987

support tickets cleaned, with missing values filled as the data description specifies.

5–17 days

is the response time range for Installation Problem tickets, the slowest category. Feedback tickets are answered within 1 to 2 days.

123

survey ratings linked to Bug and Installation Problem tickets.

How I approached it

  • Cleaned the support table with COALESCE and CASE, and converted text columns to dates and numbers.
  • Used GROUP BY to get the minimum and maximum response time for each ticket category.
  • Joined survey ratings to tickets and filtered to the two categories of interest.

The code and output

Taken from my DataCamp Workspace notebook for this project.

Task 1: clean the support table
SELECT 
	id,
	COALESCE(customer_id, 0) AS customer_id,
	COALESCE(category, 'Other') AS category,
	CASE 
		WHEN status IS NULL OR status = '-' THEN 'Resolved'
		ELSE status
	END AS status,
	COALESCE(creation_date, '2023-01-01')::DATE AS creation_date,
	COALESCE(response_time::INTEGER, 0) AS response_time,
	ROUND(COALESCE(REPLACE(resolution_time, 'hours', '')::NUMERIC, 0), 2) AS resolution_time
FROM support;

Task 2: response time by category
SELECT 
	category,
	ROUND(MIN(response_time), 2) AS min_response,
	ROUND(MAX(response_time), 2) AS max_response
FROM support
GROUP BY category

Task 3: survey ratings for Bug and Installation Problem tickets
SELECT 
	s.rating,
	t.customer_id,
	t.category,
	t.response_time
FROM survey AS s
LEFT JOIN support AS t 
	ON s.customer_id = t.customer_id
WHERE t.category IN ('Bug', 'Installation Problem')
